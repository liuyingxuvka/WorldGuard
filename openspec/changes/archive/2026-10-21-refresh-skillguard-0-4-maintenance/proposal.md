## Why

WorldGuard's author-maintenance contract and managed prompt were generated by an older SkillGuard shape, one bundled runtime model differs from the canonical package by an end-of-line byte, and the repository still tracks an obsolete author-style copy of the FlowGuard skill suite. These identities must be reduced to one current WorldGuard author unit and one global clean FlowGuard consumer authority before new maintenance evidence can be trusted.

## What Changes

- Refresh WorldGuard's explicit SkillGuard author adoption and direct generated authority to SkillGuard 0.4 while preserving its five target-declared checks and all target-owned domain depth.
- Normalize the canonical package and bundled skill runtime copy of the fuel-cell world model to exact byte parity.
- Remove the tracked local `.agents/skills` FlowGuard author copies and obsolete `.skillguard/flowguard-suite/suite-map.json` after dependency and public-entrypoint evidence confirms the global clean consumer projection is the sole project tool surface.
- Add FlowGuard existing-model, StructureMesh, TestMesh, and DevelopmentProcessFlow evidence for the one-skill/five-check maintenance boundary and the structure reduction.
- Produce local source/consumer projection and affected-validation evidence without installing, publishing, or changing WorldGuard's seven internal Guard semantics.

## Capabilities

### New Capabilities

- `worldguard-maintenance-authority`: Defines current SkillGuard author authority, exact model/runtime identity, the global FlowGuard consumer boundary, five-check validation ownership, and bounded local closure.

### Modified Capabilities

None. WorldGuard runtime behavior, public API, single skill entrypoint, and seven internal Guard routes are unchanged.

## Impact

- Author-only WorldGuard SkillGuard manifest, managed block, contract trio, validation plan, and evidence.
- FlowGuard project records and maintenance structure/test/process models.
- Exact-byte normalization of `worldguard/examples/fuel_cell/world_model.yaml` and its bundled skill copy.
- Removal of obsolete tracked `.agents/skills/**` and `.skillguard/flowguard-suite/suite-map.json`; project guidance continues to resolve FlowGuard through the current global consumer projection.
- No global installation, package publication, Git commit/push/tag, release, or FlowGuard main-repository change.
